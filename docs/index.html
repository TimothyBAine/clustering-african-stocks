    Which clusters are real?

    A cluster is only useful if it survives small changes to the data. Each cluster was re-estimated on 50 block-bootstrapped histories, which resample 20-day stretches so stale prices and autocorrelation are preserved. Jaccard recovery measures how much of the original cluster comes back each time.

    What does "similar" mean?

    Similarity is a modelling choice. Each view was clustered on the first year of data and scored on the second: does a cluster still co-move, and does it explain later differences in volatility, drawdown and liquidity? Scores are z-scores against random clusters of the same sizes, so the 5-group listing exchange reference and a 6-cluster view compete fairly.

    Pair screen

    Cointegration tested only within clusters, with false-discovery control. Hedge ratio fitted in-sample, then rechecked out of sample. A shortlist for research, not trading signals: shorting is restricted on most of these exchanges. The strongest pairs are mostly ETFs tracking the same index, which is a sanity check that the screen works rather than a discovery.

    Method and caveats

    • Data. Daily prices from the Mansa API for NGX, JSE, NSE, GSE and EGX, converted to US dollars at each day's rate. Stocks need at least 120 trading days.
    • Distance. d = √(2(1 − ρ)) between daily log returns, clustered with Ward linkage. The 2-D map is classical MDS of the same distances, so it is an approximation of the real structure.
    • FX matters. Converting to dollars puts each country's currency moves into every stock it lists. Part of "clusters are countries" is "clusters are currencies".
    • Thin trading. Many frontier-market stocks don't trade most days, so their prices look flat and their correlations look low. Some have no price changes at all in the sample. Those land together because they all look like nothing is happening, not because they are similar businesses.
    • ETFs. The JSE universe includes ETFs, which can become cluster representatives.
    • Backtest limits. About one year of out-of-sample data, a flat 50 bps cost per unit of turnover and no bid-ask spread. It compares strategies; it does not forecast returns.
